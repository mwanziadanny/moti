# GariNice — Kenyan vehicle marketplace (frontend)

A production-grade car marketplace for Kenya: buyers search, filter and contact sellers; private sellers and dealers list and manage vehicles; admins moderate and run the marketplace.

**Stack:** React 19 · Vite 8 · Tailwind CSS 4 · React Router 7 · TanStack Query 5 · Zod 4 · Vitest + Testing Library.

> **Frontend-first:** the full REST contract (`/api/*`) is implemented by an in-browser mock backend (`src/api/mock`), so every button works end to end today — auth, RBAC, listings, moderation, messaging, favourites, reports, M-Pesa payments with signed webhooks, analytics and admin tools. Point `VITE_API_URL` at the real backend and the same UI talks to it with no code changes. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 26 tests: API critical flows + UI journeys
npm run lint
npm run build      # generates sitemaps, then production build in dist/
npm run preview
```

## Testing

- `src/api/mock/__tests__/criticalFlows.test.js` covers the spec's 14 critical flows at the API level: search with typo tolerance, register, save, message, seller inbox, create listing, admin approval, public search, package purchase, signed webhook, duplicate/forged webhook rejection, mark sold. It also covers RBAC, rate limiting and reports.
- `src/test/app.test.jsx` renders the real routes against the mock backend: home, Prado search to detail, filter chips, SEO landing pages, 404s, dealer storefronts, CMS, save-prompts-login-then-saves, protected redirects, messaging, seller dashboard, wizard validation and admin access control.
